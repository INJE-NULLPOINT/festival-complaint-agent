# 출처·AI 활용 신고서

팀명 철철철 · 작품명 실시간 축제 민원 관제 AI Agent · 저장소 https://github.com/INJE-NULLPOINT/festival-complaint-agent (공개 저장소)

운영규정(출처·AI 활용 신고)과 서류평가 체크리스트 12번에 따라 주요 AI 도구, 공개 코드, 모델, 데이터, 외부 API, 기존자산의 출처와 신규개발분을 적는다. 오픈소스 버전은 2026-10-01 설치본 기준이다.

## 1. AI 도구 활용

| 구분 | 도구 | 용도 | 활용 범위 |
|---|---|---|---|
| 개발 보조 | Claude Code (Anthropic) | 코드 작성·디버깅·테스트·문서 초안 작성·자료 조사 보조 | 아래 1-1 표로 'AI가 만든 부분'과 '팀이 정한 부분'을 나눠 적음 |
| 에이전트 모델 (제출·시연) | Claude Opus 5.5 (`claude-opus-5-5`), Claude Code CLI(`claude -p`, `LLM_BACKEND=claude_code`) 경유 | 에이전트 5종의 판단(주기 계획, 민원 분류, 인용 선별, 우선순위 조정, 브리핑·조치요청서 문장) | 점수·등급·순위 계산에는 쓰지 않음(결정적 함수). API 키 없이 제출·시연(사용자 결정 2026-10-05) |

### 4-1. 심각도·안전 판단의 참고 문헌 (코드·데이터로 쓰지 않음, 규칙 설계의 근거로만 인용)
