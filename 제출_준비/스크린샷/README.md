화면마다 **최신본만** 둡니다. 이름은 `화면_상태_폭_모드.png` 입니다. 옛 디자인은 git 기록에만 남아 있습니다.

- 폭: `1280` PC · `390` 폰 · `320` 작은 폰
- 모드: `light` 라이트 · `dark` 다크 (운영체제 설정을 따릅니다)
- 모든 화면은 임시 SQLite + local 대역(운영 Supabase 미사용)으로 찍었습니다. 민원은 시연용으로 지어낸 가상 민원이라
  헤더에 **'합성 데이터 포함'** 배지와 'AI: 규칙(개발용)' 표시가 보입니다. 가리지 않습니다.
- 새로 찍은 스크린샷은 이 폴더에만 넣고, 같은 장면의 옛 파일은 지웁니다.
