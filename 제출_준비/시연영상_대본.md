# 시연영상 대본 (별지 2) — 3분

> 원칙(별지 2): 홍보 영상처럼 편집하지 않고 **실제 입력 → Agent 판단 → Tool 호출 → 결과**가 보이게 찍는다.
> 별지 3의 6구간을 3분에 맞춰 줄였다. 시간은 목표값이고, 리허설에서 잰 뒤 고친다.
> 자막(처음부터 끝까지 화면 아래): **"배경 민원 24건과 유등터널 혼잡 2건은 시연용으로 만든 가상 민원입니다."**

## 준비 (녹화 전)

```powershell
cd festival_agent
$env:DB_PATH = "output/demo_festival.db"
node server/scripts/demo_scenario.ts --reset --lead 120   # 배경 24건 투입, T = 지금 + 120초
node server/worker.ts                                      # 창 2 (같은 DB_PATH)
node server/webapi.ts --host 0.0.0.0                       # 창 3 (같은 DB_PATH)
cd web; npm run phone                                      # 창 4 — 휴대폰은 http://<PC IP>:4173/?v=qr
```

- 모델: Claude Opus 5.5, Claude Code CLI 경유(`LLM_BACKEND=claude_code`).
- 배경 24건 분류가 끝난 것을 관제 화면에서 확인한 뒤 T에 맞춰 녹화를 시작한다.
- 운영 Supabase가 아닌 시연 DB(SQLite)로 돈다.
- 휴대폰용 `npm run phone`(4173)은 아직 점검하지 않았다. PC 화면만 찍으면 vite 개발 서버(5173)로도 된다.
