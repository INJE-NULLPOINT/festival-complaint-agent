# 실제 리뷰 수집 가이드 (할일 D6-6)

> **수집은 사람이 직접 합니다.** 문장을 지어내거나 고쳐 쓰거나, AI로 만들어 섞으면 안 됩니다.
> 합성 데이터를 실제 수집분으로 내면 설명회 주의사항 13번(허위·조작 금지) 위반입니다.
> 지금 있는 `festival_agent/seed/dev_sample.csv` 는 개발용 합성 데이터입니다. 제출 데이터로 쓰지 않습니다.

## 1. 무엇을 모으나

- 대상: 진주남강유등축제 방문 후기 중 **불편·칭찬이 드러난 문장** (주차, 화장실, 가격, 안내, 혼잡, 안전, 긍정)
- 분량: 목표 100건 이상 (할일 D6-6 판정은 출처 URL 이 있는 행 100개부터 통과)
- 방법: **손으로 옮겨 적기.** 크롤러·자동 수집 도구는 쓰지 않습니다 (신청서에 "크롤링하지 않음"으로 적음)
- 한 리뷰에 불편이 여러 개면, 문장 단위로 나눠 여러 행에 적어도 됩니다. 단, 원문 표현은 그대로 둡니다.

## 3. 적는 방법

템플릿: `festival_agent/scripts/templates/real_reviews_template.csv` 를 복사해서 엑셀이나 구글 시트로 채운 뒤 **CSV(UTF-8)** 로 저장합니다.
템플릿을 `seed/` 폴더에 두지 마세요. 원문 파일도 `seed/` 밖에 둡니다.

| 열 | 필수 | 적는 법 |
|---|---|---|
| `posted_at` | 필수 | 리뷰 작성 시각. `2025-10-05T19:20:00` 형식. **날짜만 보이면 `2025-10-05` 처럼 날짜만.** 시각을 추정해서 넣지 않습니다 |
| `zone` | 선택 | 리뷰에 장소가 분명히 나오면 구역 이름 8개 중 하나(진주교 남단 주차장 · 촉석루 일원 · 남강 수상무대 · 유등터널 · 먹거리장터 · 소망등 달기 구역 · 임시 화장실 A · 셔틀버스 승강장). 애매하면 빈칸 — 빈칸이나 모르는 이름은 첫 구역으로 넣지 않고 '구역 미상'으로 저장됩니다 |
| `text` | 필수 | 원문 그대로. 이름·연락처·계정 ID가 있으면 지우지 말고 그대로 두세요. 정제 스크립트가 가립니다 |
| `_label_hint` | 선택 | 사람이 판단한 정답 유형: `parking` `restroom` `price` `guide` `crowd` `safety` `positive`. 분류 정확도 측정에 씁니다. 두 사람이 따로 붙이고 다르면 협의해서 정하면 더 좋습니다 |
| `source_url` | 필수 | 리뷰가 있는 공개 주소. 없으면 그 행은 버려집니다 |
| `source_name` | 권장 | 출처 종류 (예: 블로그, 지도 앱 리뷰, 커뮤니티) |
| `collected_at` | 권장 | 옮겨 적은 날짜 |

## 4. 정제와 사용

```bash
cd festival_agent
python scripts/clean_reviews.py ../수집원문.csv          # → seed/real_reviews.csv
python cli.py reset --all
python cli.py replay start --file real_reviews.csv --speed 300   # 리플레이
python scripts/measure_accuracy.py --seed seed/real_reviews.csv --backend anthropic   # 정확도 (_label_hint 있는 행)
python cli.py todo                                        # D6-6 판정 확인
```

정제 스크립트가 하는 일: 개인정보 마스킹, 공백 정리, 5~500자 밖 제외, 같은 문장 중복 제거, 출처 URL 없는 행 제외, 유형·구역 값 검사.
문장 내용은 바꾸지 않습니다. 결과 요약(제외 사유별 건수)을 이 문서 5절에 옮겨 적으세요.

**시각이 날짜뿐인 리뷰**가 많으면 리플레이에서 같은 시각에 몰려 들어옵니다. 시각을 지어내 흩뿌리지 말고, 그렇게 몰린다는 사실을 보고서에 적으세요.
